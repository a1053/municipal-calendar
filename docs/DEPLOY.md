# Publicar el feed

## Opción recomendada: GitHub Pages

1. Crea un repositorio y sube el proyecto.
2. En Settings → Pages selecciona GitHub Actions como fuente.
3. Añade un workflow de Pages o publica `public/` con tu proveedor estático.
4. La URL final será algo como `https://TU-USUARIO.github.io/TU-REPO/municipal.ics`.
5. En Google Calendar: Otros calendarios → Desde URL. En Apple Calendar: Archivo → Nueva suscripción a calendario. En Outlook: Agregar calendario → Suscribirse desde web.

## Seguridad

El feed no contiene información privada. No expongas endpoints de administración sin autenticación.
